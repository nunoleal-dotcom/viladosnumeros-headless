# Documentos dos Investidores

Esta pasta contém todos os documentos disponibilizados aos investidores e acionistas.

## 📁 Estrutura de Pastas

### 📊 `relatorios/`
Relatórios financeiros e de gestão
- Contas Anuais (por ano)
- Relatórios de Gestão
- Pareceres do Auditor
- Informações Financeiras

### 📢 `assembleia/`
Documentação de Assembleias Gerais
- Convocatórias
- Boletins de Voto
- Atas das Assembleias
- Propostas de Deliberação

### 📜 `certificados/`
Documentação Corporativa
- Certidão Permanente
- Estatutos Sociais
- Regulamentos

### 📣 `comunicados/`
Comunicados ao Mercado
- Press Releases
- Avisos aos Acionistas
- Anúncios Oficiais

### 📋 `regulamentos/`
Regulamentos Internos
- Regulamento de Funcionamento
- Código de Conduta
- Políticas Internas

---

## 💾 Como Adicionar Documentos

1. Coloque o PDF na pasta correspondente
2. Use o nome: `AAAA-MM-Descricao.pdf` (ex: `2024-01-Contas-Anuais.pdf`)
3. Os documentos aparecem automaticamente no site na página de Investidores
