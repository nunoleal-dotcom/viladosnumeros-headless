## 📋 Nomenclatura de Arquivos

Use este padrão para organizar melhor:

```
01-fachada.jpg
02-entrada.jpg
03-sala.jpg
04-cozinha.jpg
05-quarto.jpg
06-detalhes.jpg
```

Ou por categoria:

```
fachada-01.jpg
interior-sala-01.jpg
interior-quarto-01.jpg
ambiente-comum-01.jpg
```

---

## 🖼️ Formatos Recomendados

- **Fotografias:** JPG (qualidade 85-90%)
- **Infográficos:** PNG
- **Tamanho:** Mínimo 1920x1080px
- **Tamanho máximo:** 5MB por imagem

---

## 🔗 Como Usar no Site

As imagens são referenciadas assim:

```html
<img src="/images/projects/campo-de-ourique/01-fachada.jpg" />
```

E aparecem automaticamente nos carrosséis dos projetos.

---

## 📊 Dicas de Organização

1. **Numbere sequencialmente** para controlar a ordem
2. **Use nomes descritivos** em minúsculas com hífen
3. **Mantenha consistência** entre projetos
4. **Delete duplicatas** regularmente
5. **Backup** das imagens originais em alta resolução
